# 🇬🇧 English Practice Bot

Telegram-бот для разговорной практики английского и веб-панель для преподавателя.

- Преподаватель добавляет учеников, выдаёт каждому **личную ссылку** и назначает **занятия**: тема, уровень и время, когда ученик может общаться с ИИ.
- Вне занятий бот с учеником не разговаривает. Свободную практику можно включить отдельно.
- После разговора ученик получает разбор ошибок, а преподаватель — копию с оценкой и статистику.

Всё работает **бесплатно**: Cloudflare Workers + база D1 + Google Gemini. Карта не нужна.

## Как это работает

```
Панель (телефон/компьютер)            Telegram                    Ученик
──────────────────────────            ────────                    ──────
1. Добавить ученика «Маша»
2. 🔗 Сгенерировать ссылку  ──────►  t.me/бот?start=k7f2x9  ──►  открывает, жмёт «Старт»
                                                                   → привязан к карточке «Маша»
3. Назначить занятие:
   At the restaurant, A2,
   завтра 18:00–19:00        ──────►  🔔 «Открыто занятие!»  ──►  переписывается с ИИ
                                                                   /finish → разбор ошибок
4. Видит статистику и        ◄──────  📝 копия разбора 7/10
   переписку в панели
```

- **Ссылка одноразовая.** Если её перешлют другу, она не сработает. Сменил ученик телефон — жмёшь «Сгенерировать новую ссылку».
- **Занятие закончилось, а ученик не нажал /finish** — разбор придёт автоматически.
- **Цель занятия:** минимум N сообщений. Занятие получает статус «Выполнено», «Частично» или «Пропущено».
- **Слова темы:** в статистике видно, какие слова из списка ученик употребил.

## Панель преподавателя

Открывается по адресу бота, например `https://english-bot.ИМЯ.workers.dev`. Вход по паролю.

- **Главная:** что открыто сейчас, ближайшие занятия, последние разборы.
- **Ученики:** список, поиск, добавление по одному или списком. Списком — сразу со ссылками для всех.
- **Карточка ученика:** кнопка «🔗 Сгенерировать ссылку», статистика (выполненные занятия, средняя оценка, график оценок, активность, слова), занятия, вся переписка с разборами, уровень и настройки ученика.
- **Темы:** свои сценарии для ИИ со списком слов.
- **Настройки:** подключить свой Telegram для уведомлений, лимиты, язык разбора.

**Как приложение на телефоне:**
- Android (Chrome): ⋮ → «Установить приложение»;
- iPhone (Safari): «Поделиться» → «На экран „Домой“».

## Установка (~15 минут)

### 0. Что понадобится
- компьютер с [Node.js](https://nodejs.org) (версия LTS);
- **токен бота**: в Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен вида `123456:ABC...`;
- **ключ Gemini**: [aistudio.google.com](https://aistudio.google.com) → *Get API key* → *Create API key*;
- бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up).

### 1. Подготовка
В папке проекта:
```bash
npm install
npx wrangler login
```

### 2. База данных
```bash
npx wrangler d1 create english-bot
```
Скопируй `database_id` из вывода в `wrangler.toml` вместо `ВСТАВЬ_СЮДА_ID_БАЗЫ`. Затем создай таблицы:
```bash
npm run db:init
```

### 3. Выложить
```bash
npm run deploy
```
В конце появится адрес вида `https://english-bot.ИМЯ.workers.dev`.

### 4. Секреты
Каждая команда спросит значение:
```bash
npx wrangler secret put BOT_TOKEN
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put ADMIN_PASSWORD
```
- `WEBHOOK_SECRET` — придумай длинную строку из латинских букв и цифр, например `myBot2026superSecretKey77`.
- `ADMIN_PASSWORD` — пароль от панели.

### 5. Подключить Telegram
Открой в браузере:
```
https://english-bot.ИМЯ.workers.dev/setup?key=ТВОЙ_WEBHOOK_SECRET
```
Должно показать `"ok":true`. Готово! 🎉

### 6. Первый вход
1. Открой `https://english-bot.ИМЯ.workers.dev` и войди с паролем.
2. **Настройки → «Подключить мой Telegram»**, чтобы получать разборы.
3. **Ученики → «+ Ученик» → «🔗 Сгенерировать ссылку»** → отправь ссылку ученику.
4. В карточке ученика **«+ Занятие»**.

## Обновление
После изменений в коде:
```bash
npm run deploy
```
Если в `schema.sql` появились новые таблицы, ещё раз выполни `npm run db:init` (существующие данные не трогаются).

## Полезное
- **Логи:** `npx wrangler tail`.
- **«ИИ перегружен»:** кончился бесплатный лимит Gemini. Он общий на весь бот, а не на ученика. Уменьши «лимит сообщений в день» в настройках панели. Текущие лимиты смотри в AI Studio.
- **Модель:** `GEMINI_MODEL` в `wrangler.toml`. `gemini-flash-latest` — всегда актуальная Flash-модель.
- **Приватность:** на бесплатном тарифе Google может использовать переписку для улучшения моделей. Ученикам стоит сказать, чтобы не писали личные данные.
- **Лимиты Cloudflare (бесплатно):** 100 000 запросов в день и 5 ГБ базы. Для 30–40 учеников с огромным запасом.

## Структура
```
src/index.ts     — вход: webhook, /setup, API, расписание (каждые 5 мин)
src/bot.ts       — бот для учеников
src/lessons.ts   — занятия: статусы, разбор, уведомления, учёт слов
src/cron.ts      — уведомления об открытии занятий и авто-разбор
src/api.ts       — API для веб-панели
src/auth.ts      — вход в панель по паролю
src/prompts.ts   — инструкции для ИИ
src/gemini.ts    — запросы к Gemini
src/telegram.ts  — отправка сообщений
src/db.ts        — работа с базой
public/          — веб-панель (устанавливается как приложение)
schema.sql       — таблицы и стартовые темы
```
